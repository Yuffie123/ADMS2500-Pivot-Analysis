# Financial Data Analysis Using Excel Pivot Tables (ADMS 2500 Project)

This project was completed as part of the ADMS 2500: Introduction to Financial Accounting course at York University.  
It demonstrates financial data cleaning, pivot table analysis, and profitability reporting using Microsoft Excel.

## Objectives
- Clean and organize sales and cost data for a four-year period (2015–2018)
- Create calculated columns for Sales Revenue, Total Cost, and Gross Profit
- Build pivot tables and pivot charts for sales, cost, and gross profit analysis
- Calculate Gross Profit Percentage (using a calculated field)
- Identify the most profitable regions and brands

## Key Findings
- Sales revenue and gross profit increased steadily from 2015 to 2018.
- The Midwest region showed the most rapid growth in sales.
- Jeffrey Alexander was the most profitable brand in 2018 (by gross profit percentage).
- The overall weighted gross profit percentage in 2018 was 38.95%.

##  Tools Used
- Microsoft Excel (Pivot Tables, Calculated Fields, Charts)
- Data Cleaning and Financial Analysis Techniques
